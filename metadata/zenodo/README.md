# Uso de las plantillas

Los dos borradores de Zenodo tienen DOI reservados:

- Teoría: `10.5281/zenodo.22306586`.
- Problemas, prácticas y estudio: `10.5281/zenodo.22307022`.

Estas plantillas están preparadas para actualizar los dos borradores ya
existentes; no solicitan una nueva reserva. El DOI propio no se introduce como
un campo de metadatos: queda vinculado al borrador correspondiente en Zenodo.
Los JSON incluyen el DOI del volumen complementario como identificador
relacionado.

Citas recomendadas:

- Dalmasso, G. (2026). *Cálculo Diferencial en una Variable — Teoría* (versión
  1.0). Zenodo. https://doi.org/10.5281/zenodo.22306586
- Dalmasso, G. (2026). *Cálculo Diferencial en una Variable — Problemas,
  prácticas y estudio* (versión 1.0). Zenodo.
  https://doi.org/10.5281/zenodo.22307022

Antes de publicar cada depósito, sustituya `__PUBLICATION_DATE__` por la fecha
real en que el recurso se haga público por primera vez.
