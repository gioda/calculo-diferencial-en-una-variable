# Contribuir

Gracias por ayudar a mejorar **Cálculo Diferencial en una Variable**. Son
bienvenidos los avisos y propuestas relacionados con:

- erratas y enlaces rotos;
- posibles errores matemáticos o de contenido;
- mejoras de accesibilidad;
- mejoras de los laboratorios Python;
- problemas de construcción o reproducibilidad;
- explicaciones que podrían ser más claras.

Para una corrección localizada, abre una incidencia e indica el libro, la
página y, cuando corresponda, la sección o el número visible del ejercicio. Si
el problema es técnico, incluye el entorno y los pasos mínimos para
reproducirlo. Abre primero una incidencia antes de proponer un cambio
pedagógico sustancial.

Los cambios matemáticos o de contenido requieren una revisión cuidadosa. No
incluyas escaneos, enunciados copiados ni otros materiales protegidos de libros
de texto. Tampoco envíes soluciones, notas o recursos privados destinados al
profesorado.

Al contribuir, confirma que tienes derecho a aportar el material. El contenido
educativo y documental se acepta bajo **CC BY-SA 4.0**; el código Python, los
scripts de figuras y el código de construcción se aceptan bajo **MIT**, de
acuerdo con [`LICENSES.md`](LICENSES.md).

Todas las interacciones deben respetar el
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
